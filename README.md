# Parque Nacional Cahuita - Guía Oficial del Turista

Este proyecto consiste en una página web responsive para el Parque Nacional Cahuita, desarrollada como parte de las actividades prácticas del curso.

## Tecnologías utilizadas
- HTML5
- CSS3 (Variables, Flexbox, CSS Grid y Nesting nativo)
- Git y GitHub

## Estructura del proyecto
- `index.html`: Estructura principal del sitio.
- `estilo.css`: Hoja de estilos organizada por componentes.
- `/`: Imágenes y assets utilizados en las secciones.
